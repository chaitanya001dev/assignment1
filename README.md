# assignment1
The script in Task1 file prompts the user to input two integers 
via input() and converts them to int for calculations. 
It then computes and prints the addition, subtraction, 
multiplication, and division results using f-strings for formatted 
output.


The script in Task2 prompts the user to enter their first name and 
last name using input(). It then prints a personalized welcome 
message using an f-string to concatenate the names.
